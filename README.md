# 我带过最差的一届

3D 校园游戏试玩，支持单人 AI 课堂和真实多人房间。在更衣柜选择学生或老师，通过局内电梯进入白天教室、停电的夜晚教室、机房或阶梯教室。

## 单人网站

[打开游戏](https://nornttyy.github.io/campus-afterbell/?v=campus-57)，点击「单人开始」。其余同学与老师由本地规则 AI 控制，不需要账号、房间号或服务器。主菜单保留四种同学外观选择；身份在局内更衣柜点击即切换，地图在局内电梯选择。

单人和多人使用同一套地图、角色和道具。课前按 E 敲铃后开始 30 秒准备，老师先留在办公室，AI 同学随后从电梯进入，玩家可以自行选座。使用物品累计捣乱值，老师通过观察和声音寻找捣蛋学生；眩晕、抓取、带到木桩绑定及队友救援均保留。学生双臂留在木棍后方，不显示绳圈；单人和多人救援均为连续按住 E 1.6 秒。

多人中真人学生占用当前布局的座位，人机补足剩余的 20 或 30 个学生位；老师单独计算。短暂断线保留原角色和座位，课中永久离开不会突然生成一个新的人机，课间重算人数。

学生（真人与人机）正常步行固定为 1.8 米/秒，老师为 2.2 米/秒。人机按远座优先的顺序逐个从电梯进入，不再根据倒计时临时提速；爬行、后退及携带同学保留各自的动作速度限制。

| 操作 | 控制 |
| --- | --- |
| 移动 | W / A / S / D |
| 看向目标 | 鼠标；不支持鼠标锁定的窗口可按住右键转向 |
| 打开课桌、拿取物品、坐下、操作电脑 | 准星对准后按 E |
| 放回物品、关闭、起身 | Q，优先结束手中的操作 |
| 食物与物品使用 | 按住鼠标左键；低头按住 3 秒；松手重置进度 |
| 笔 | E 拿起后循环转笔，E 切换转笔/写字，Q 放回；不加捣乱值 |
| 投掷 | 点击即抛，长按蓄力后松手 |
| 后门、队友救援、老师板书 | 对准后按住 E；关闭后门按住 Q，有人挡门时不能开关 |
| 老师监控 | 对准控制板 E 安装或查看，Q 关闭画面 |
| 爬行 | 按住 Shift |
| 暂停 | Esc |
| 麦克风 | 仅多人模式，M |

电梯在课前集合时使用：所有真人进入轿厢后由房主选层，单人由自己选层。关门运行 3 秒后到达新楼层，每局限一次，开始下一局后恢复。

触屏有移动摇杆、拖动转向、互动、使用和爬行按钮。机房直接使用场景中的电脑屏幕：WASD 选择，E 打开，Q 返回桌面，再按 Q 离开。四个应用为 Photoshop、Unity、贪吃蛇和 VALORANT；前两个显示软件官方截图（不能操作完整软件），贪吃蛇可操作、每吃一颗食物加 1 点，VALORANT 循环播放 EDG ZmjjKK 比赛集锦片段，每实际观看 3 秒增加 1 点；缓冲、暂停和切后台不计时。老师讲台电脑显示正在玩游戏的人数。

普通食物吃完增加 1 点，老师便当增加 3 点。必须低头偷吃，松开鼠标清空进度，抬头暂停。香蕉吃完留下可投出的香蕉皮，大蒜吃完后的 5 秒内可点击左键打嗝。泡泡每圈 1.5 秒；粉红泡泡前三圈分别加 1、2、3 点，第四圈或松手时爆掉，被绑学生的橙色泡泡则松手发射。私人的咀嚼、吞咽、充气音与所有人可听到的完成声、爆泡声、打嗝声分开处理。老师可看见公共声音的白色方向弧，在设置中可关闭并保存选择。纸条和背景音乐已移除。

默认每局 10 分钟，创建房间时房主可选 5–20 分钟、目标 30–120 点。局内只有房主能在课间集合时从 Esc 暂停菜单打开「房间设置」，准备倒计时和上课期间均锁定；单人沿用课间限制。开课 120 秒后老师可部署监控，全局最多 2 台，两次部署至少相隔 115 秒。监控显示真实场景和烟雾遮挡。老师正常移动每 0.2 秒扣 1 点体力，后退每 0.6 秒扣 1 点，静止不扣；粉笔不扣体力，但零体力不能投。15 点以下平滑出现视野边缘模糊，恢复后消退。抓对捣蛋身份并绑上木桩加 20 点，绑错普通同学扣 40 点。

地图墙面与办公室白板使用无字幕的黑色教程图。局内状态提示使用上方半透明灰条、居中白字。办公室扩大并保留多组桌椅、电脑及便当抽屉；课堂增加 4×5 和 5×4 桌椅布局，沿用单桌、双桌、四桌与混合布局。

## 多人

菜单仍保留「多人联机」。GitHub Pages 只托管网页，不能运行房间服务器；没有部署公网后端时，GitHub 网站不会凭空创建联网房间。

Pages 联机入口默认不填服务器地址，会显示未接入提示并提供「先玩单人」。有独立房间服务器时可填写其 HTTPS 地址；服务器还必须允许网页来源 `https://nornttyy.github.io`，配置方法见下方服务器文档。连接前检查健康接口，HTML 错误页、无效 JSON 或错误流协议不再显示解析异常或无限重连。当前公开网站尚未连接公网房间服务器。

```sh
npm run serve:online
```

打开 `http://127.0.0.1:8931/` 创建房间，第二位玩家输入六位房间号加入。服务器运行时，同一局域网可用本机 IP 的 8931 端口连接；两名真人才能开始多人课堂。联网运行方式、HTTPS 和可选语音的限制见 [server/README.md](server/README.md)。

## 本地单人运行

```sh
python3 -m http.server 8921
```

打开 `http://127.0.0.1:8921/dist/`。Three.js 已随网站提供，无构建和安装依赖。

```sh
npm run check
npm test
```

部分模型与蒙皮测试使用本机保存的原始制作资料，未将研究视频和原始大模型上传到公开仓库。浏览器实际试玩仍需要独立检查。

## 素材和范围

学生、老师与部分道具来自用户选定并导出的 Tripo 模型，保留用户确认的外貌与原始纹理，运行时使用 Three.js 骨骼动画。地图、交互、AI 和音效为本项目实现。素材来源及许可证见 `dist/assets/models/LICENSES.txt`，Three.js 使用 MIT 许可证。

本项目参考校园捣蛋游戏玩法，未宣称与参考作品的全部模型、动作、地图、声音和规则完全一致。模型与地图的已验证结果、已知差异保存在 `docs/modeling-notes.md` 和 `docs/reference-visual-audit.md`。

GitHub Pages 从 `gh-pages` 分支根目录发布；`main` 保存工程源码。发布工具 `scripts/publish.py` 仅上传已跟踪文件，新增运行文件必须先加入索引；本地研究素材、截图和凭据不参与发布。
