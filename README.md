# 下课别走

3D 校园游戏试玩，支持单人 AI 课堂和真实多人房间。可选择学生或老师，进入白天教室、晚自习或机房。

## 单人网站

[打开游戏](https://nornttyy.github.io/campus-afterbell/?v=network-53)，点击「单人开始」。其余同学与老师由本地规则 AI 控制，不需要账号、房间号或服务器。可在主菜单选择身份、课堂和四种同学外观。

单人和多人使用同一套地图、角色和道具。课前按 E 敲铃后开始 30 秒准备，老师先留在办公室，AI 同学随后从电梯进入，玩家可以自行选座。使用物品累计捣乱值，老师通过观察和声音寻找捣蛋学生；眩晕、抓取、带到木桩绑定及队友救援均保留。

| 操作 | 控制 |
| --- | --- |
| 移动 | W / A / S / D |
| 看向目标 | 鼠标；不支持鼠标锁定的窗口可按住右键转向 |
| 打开课桌、拿取/放回物品、坐下/起身、操作电脑 | 准星对准后按 E |
| 食物与物品使用 | 按住鼠标左键；普通食物 3 秒 |
| 笔 | 对准按 E 拿起后自动循环写字，不加捣乱值；再按 E 放回 |
| 投掷 | 点击即抛，长按蓄力后松手 |
| 后门开关、队友救援、老师板书 | 对准后按住 E |
| 爬行 | 按住 Shift |
| 暂停 | Esc |
| 麦克风 | 仅多人模式，M |

电梯在课前集合时使用：所有真人进入轿厢后由房主选层，单人由自己选层。关门运行 3 秒后到达新楼层，每局限一次，开始下一局后恢复。

触屏有移动摇杆、拖动转向、互动、使用和爬行按钮。机房电脑包含学习和贪吃蛇，每吃一颗食物增加 1 点捣乱值。香蕉吃完留下可投出的香蕉皮，大蒜吃完后的 5 秒内可点击左键打嗝；泡泡糖与被绑吹泡泡使用逐圈蓄力。

## 多人

菜单仍保留「多人联机」。GitHub Pages 只托管网页，不能运行房间服务器；没有部署公网后端时，GitHub 网站不会凭空创建联网房间。

Pages 联机入口默认不填服务器地址，会显示未接入提示并提供「先玩单人」。有独立房间服务器时可填写地址；连接前检查健康接口，HTML 错误页、无效 JSON 或错误流协议不再显示解析异常或无限重连。当前公开网站尚未连接公网房间服务器。

```sh
npm run serve:online
```

打开 `http://127.0.0.1:8931/` 创建房间，第二位玩家输入六位房间号加入。服务器运行时，同一局域网可用本机 IP 的 8931 端口连接；两名真人才能开始多人课堂。联网运行方式、HTTPS 和可选语音的限制见 [server/README.md](server/README.md)。

## 本地单人运行

```sh
python3 -m http.server 8921
```

打开 `http://127.0.0.1:8921/dist/`。Three.js 已随网站提供，无构建和安装依赖。

```sh
npm run check
npm test
```

部分模型与蒙皮测试使用本机保存的原始制作资料，未将研究视频和原始大模型上传到公开仓库。浏览器实际试玩仍需要独立检查。

## 素材和范围

学生、老师与部分道具来自用户选定并导出的 Tripo 模型，保留用户确认的外貌与原始纹理，运行时使用 Three.js 骨骼动画。地图、交互、AI 和音效为本项目实现。素材来源及许可证见 `dist/assets/models/LICENSES.txt`，Three.js 使用 MIT 许可证。

本项目参考校园捣蛋游戏玩法，未宣称与参考作品的全部模型、动作、地图、声音和规则完全一致。模型与地图的已验证结果、已知差异保存在 `docs/modeling-notes.md` 和 `docs/reference-visual-audit.md`。

GitHub Pages 从 `gh-pages` 分支根目录发布；`main` 保存工程源码。发布工具 `scripts/publish.py` 仅上传已跟踪文件，新增运行文件必须先加入索引；本地研究素材、截图和凭据不参与发布。
