# 下课别走

浏览器里的 3D 校园捣蛋游戏。当前版本包含可玩的课堂模式：玩家坐在课桌前，观察老师，和四位 AI 同学配合完成小动作。

## 试玩

[公开试玩](https://nornttyy.github.io/campus-afterbell/)

桌面浏览器横屏体验最佳。点击「开始上课」即可进入。

- `1 / 2 / 3`：选择零食、纸条、手机。
- 按住 `空格` 或画面下方「按住行动」：开始小动作；松开立即收起。
- `Q`：请同学掩护，有冷却时间。
- 移动鼠标：轻微转头观察。
- `Esc`：暂停；切换窗口会自动暂停。

在铃响前达到目标分数。老师回头前有动作和提示；被发现三次，本局结束。每局老师的观察顺序不同。

## 本地运行

无构建依赖，源文件即运行文件。需要支持 WebGL 的浏览器。

```sh
python3 -m http.server 8920 --directory dist
```

打开 `http://localhost:8920`。

```sh
npm run check
npm test
```

## 版本范围

这是课堂玩法的可玩开发版，包含主菜单、角色切换、可调声音/画质、老师行为、四位 AI 同学、第一人称双手动作、胜负与重开。其他校园模式尚未实现，菜单入口保持锁定。没有网络多人、账号、支付或排行榜服务。

语音使用浏览器中已安装的中文语音。没有可用中文语音时显示短字幕；不需要麦克风权限。声音首次点击后启动。

## 实现与素材

- 场景、人物、桌椅、道具、纹理和动画在 Three.js 中以可编辑几何与代码构建。
- 标题为生成的独立透明 PNG，提示词记录在 `docs/art-prompts.md`。
- Three.js 使用 MIT 许可证，见 `dist/vendor/THREE-LICENSE.txt`。
- 风格研究参考校园喜剧游戏《我带过的最差一届》的公开展示，本项目没有使用其原始模型、音频、代码或商标标题。

GitHub Pages 从 `gh-pages` 分支发布，该分支仅包含 `dist` 内容。

更新发布（需已登录有仓库写权限的 GitHub CLI）：

```sh
git add dist docs scripts README.md package.json qa .gitignore
python3 scripts/publish.py
```

发布脚本通过 GitHub 文件接口上传，并在更新分支前检查远程版本，避免覆盖他人的提交。
