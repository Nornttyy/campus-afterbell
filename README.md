# 下课别走

浏览器里的 3D 校园游戏开发试玩。可选择学生或老师，游玩白天教室、晚自习和机房。学生局是一名本地玩家、四名 AI 同学和一名 AI 老师；老师局由玩家寻找随机混入三十个座位的五名 AI 捣蛋学生。当前是本地 AI 试玩。

## 试玩

[公开试玩](https://nornttyy.github.io/campus-afterbell/)

使用支持 WebGL 的桌面浏览器，点击「开始上课」。完整操作需要键盘和鼠标。

| 操作 | 控制 |
| --- | --- |
| 打开课桌、拿取物品、放平或竖起书本 | 中心瞄准后按 `E` |
| 使用零食、纸条、手机 | 按住鼠标左键累计 3 秒，松开仍持物 |
| 放回物品 | `Q`，需坐在课桌前 |
| 转头、低头 | 鼠标移动；未锁定鼠标时按住右键拖动 |
| 起身、在附近空座坐下 | `空格` |
| 离座后移动 | `W / A / S / D` |
| 蹲下 | 按住 `C` 或左 `Ctrl` |
| 投掷烟雾弹 | 抽屉内随机出现，拿取后点击即抛；长按蓄力、松手投掷 |
| 暂停 | `Esc` 或右上角暂停按钮；切换窗口自动暂停 |

坐着完成小动作可增加全队捣乱值，达到 100 时学生获胜。老师通过视野、声响和记忆调查同学，粉笔命中使其眩晕；靠近抓住后颈后，必须带到木桩才能绑住。队友可靠近、中心瞄准并按住 E 解救；五名捣蛋学生同时被绑住才由老师获胜。当前没有倒计时。

100 的目标、动作奖励和烟雾持续时间都是本试玩的开发调校，详见[当前玩法说明](docs/gameplay.md)，不是原作公布的参数。

## 本地运行

无构建步骤，Three.js 已随静态文件提供。无需 API 账号或密钥。

```sh
python3 -m http.server 8920 --directory dist
```

打开 `http://localhost:8920`。

```sh
npm run check
npm test
```

## 版本范围

`restraint-26` 保留男女同学的 Tripo 蒙皮模型、十段课堂动作和眼镜同学，并补充：

- 老师身份：中心瞄准、左键投粉笔，命中后靠近按 E 抓住同学，走到空木桩前按 E 绑住；Q 可放下；粉笔会被课桌、竖书和显示器挡住。五名捣蛋学生每局重新分配座位，普通同学误判不计入抓获人数。
- 木桩救援：学生靠近被绑队友按住 E 1.6 秒解救；松开或走远会中断。AI 同学会择机救人，获救同学会返回座位。被抓与被绑使用独立骨骼挣扎姿势。
- 晚自习：夜间光照和随老师朝向移动的手电；AI 老师的观察范围与手电锥角对应。
- 机房：实际显示器和键盘；学生 E 打开电脑游戏，按住左键玩，Q 切回课件。电脑游戏画面、手指动作和捣乱值跟随操作。
- 删除直接显示教师怀疑值的 HUD 和队友实时行动标记。保留中心瞄准、使用圆环、必要操作提示。
- 保留三格随机抽屉、独立 3 秒补货，以及有落地等待的抛物线烟雾弹。男女同学使用同一套已修正课堂骨骼动作，教师模型保持用户指定的旧版。

已有设置、暂停、重开和胜负流程。声音仍为浏览器合成音乐和音效，没有自然语音或麦克风功能；没有真实联网对局。麻醉枪、无人机、墨水、摄像头、雷达和完整原版地图尚未完成。新增课堂是本地实现，未宣称与原版布局、数值及全部操作一致。制作经验见[人物与地图制作记录](docs/modeling-notes.md)。

## 实现与素材

- 男女学生来自用户的 Tripo 模型，在 Blender 中保留原贴图、修正手指权重并制作骨骼动作，运行时使用 Three.js。
- 课桌基于 Poly Haven 的 CC0 School Desk 01，保留可独立滑动的抽屉；其他场景、老师和部分道具仍为可编辑程序几何。素材出处见 `dist/assets/models/LICENSES.txt`。
- 标题为生成的独立透明 PNG，提示词记录在[生成素材记录](docs/art-prompts.md)。
- Three.js 使用 MIT 许可证，见 `dist/vendor/THREE-LICENSE.txt`。
- 研究参考《我带过的最差一届》的官方展示；[原作玩法核验](docs/reference-gameplay.md)单独列出已证实和未知的内容。本试玩不是原作的一比一复现，运行素材不使用其截图、模型、音频或代码。

GitHub Pages 从 `gh-pages` 分支发布，该分支仅包含 `dist` 内容。

更新发布（需已登录有仓库写权限的 GitHub CLI）：

```sh
git add dist docs scripts README.md package.json qa .gitignore
python3 scripts/publish.py
```

发布脚本上传 Git 已跟踪文件，并在更新分支前检查远程版本。研究用的本地参考图片保留在 `docs/reference-media/`，该目录已忽略，不作为网站素材或公开文档附件发布。
