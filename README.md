# 下课别走

浏览器里的 3D 校园游戏开发试玩。当前可玩的是学生视角的课堂模式：一名本地玩家、四名 AI 同学、一名 AI 老师，以及二十五名普通 NPC 同学。

## 试玩

[公开试玩](https://nornttyy.github.io/campus-afterbell/)

使用支持 WebGL 的桌面浏览器，点击「开始上课」。完整操作需要键盘和鼠标。

| 操作 | 控制 |
| --- | --- |
| 选择零食、纸条、手机 | `1 / 2 / 3` 或物品按钮 |
| 使用物品，松开收起 | 按住鼠标左键、`空格` 或「按住使用」按钮 |
| 转头、低头 | 鼠标移动；未锁定鼠标时按住右键拖动 |
| 起身、在附近空座坐下 | `E` 或「起身 / 坐下」按钮 |
| 离座后移动 | `W / A / S / D` |
| 蹲下 | 按住 `C` 或左 `Ctrl` |
| 使用一枚烟雾 | `Q` 或「烟雾」按钮，每局一枚 |
| 暂停 | `Esc` 或右上角暂停按钮；切换窗口自动暂停 |

坐着完成小动作可增加全队捣乱值，达到 100 时学生获胜。老师通过视野、声响和记忆调查同学，确认后走近、举粉笔并罚站。你被抓后仍可转头看队友继续；五名捣蛋学生全部被抓才由老师获胜。当前没有倒计时。

100 的目标、动作奖励和烟雾持续时间都是本试玩的开发调校，详见[当前玩法说明](docs/gameplay.md)，不是原作公布的参数。

## 本地运行

无构建步骤，Three.js 已随静态文件提供。无需 API 账号或密钥。

```sh
python3 -m http.server 8920 --directory dist
```

打开 `http://localhost:8920`。

```sh
npm run check
npm test
```

## 版本范围

0.4 更新学生与教师的脸型、头发、连续袖管/裤腿及第一人称手部；教室使用混合书本摆放、可滑动抽屉和调整后的窗侧光照。人物仍有外观差距，制作经验与待改项记录在[人物与地图制作记录](docs/modeling-notes.md)。

已实现主菜单、男女同学选择、音量/画质/场景动态设置、第一人称桌下动作、离座移动与碰撞、烟雾遮挡、罚站、胜负与重开。设置保存在本地浏览器中。

老师和同学使用本地感知、记忆与行为选择规则，不调用 LLM。声音是浏览器合成的音乐与音效，没有人声、语音合成或语音对话；不使用麦克风。当前没有真正联机，也不能扮演教师。「课间追逐」「校园寻物」只是锁定的待定入口。

## 实现与素材

- 场景、人物、桌椅、道具、纹理和动画在 Three.js 中以可编辑几何与代码构建。
- 标题为生成的独立透明 PNG，提示词记录在[生成素材记录](docs/art-prompts.md)。
- Three.js 使用 MIT 许可证，见 `dist/vendor/THREE-LICENSE.txt`。
- 研究参考《我带过的最差一届》的官方展示；[原作玩法核验](docs/reference-gameplay.md)单独列出已证实和未知的内容。本试玩不是原作的一比一复现，运行素材不使用其截图、模型、音频或代码。

GitHub Pages 从 `gh-pages` 分支发布，该分支仅包含 `dist` 内容。

更新发布（需已登录有仓库写权限的 GitHub CLI）：

```sh
git add dist docs scripts README.md package.json qa .gitignore
python3 scripts/publish.py
```

发布脚本上传 Git 已跟踪文件，并在更新分支前检查远程版本。研究用的本地参考图片保留在 `docs/reference-media/`，该目录已忽略，不作为网站素材或公开文档附件发布。
