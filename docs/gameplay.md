# 当前课堂试玩

本文说明仓库当前实现。原作的一手证据和未知机制见[原作玩法核验](reference-gameplay.md)；下列数值、机器人策略和按键均属于本地试玩。

## 一局怎么进行

教室有三十个座位：玩家和四名 AI 同学属于捣蛋学生，另外二十五名普通 NPC 只会读书、写字、挠头或翻页。玩家只能扮演学生，当前没有联机或教师玩家。

坐下后选择零食、纸条或手机，按住使用，松开藏起。三种动作各自保存未完成进度，可以重复完成，也可以切换；没有个人三项任务清单。只有坐着完成动作才增加全队捣乱值，站立使用不涨值。

全队捣乱值达到 100，学生获胜。老师确认某人的违规行为后，会靠近并举粉笔，将该人罚到讲台旁。玩家被抓不会立即结束对局，仍可转头观看队友；五名捣蛋学生全部被抓，老师获胜。当前没有倒计时、三次全局失败或罚站救援。

## 控制方式

| 功能 | 键鼠与按钮 |
| --- | --- |
| 零食 / 纸条 / 手机 | `1 / 2 / 3` 或对应物品按钮 |
| 按住使用 / 松手藏起 | 鼠标左键、`空格` 或「按住使用」按钮 |
| 转头和低头 | 锁定鼠标后移动鼠标；未锁定时按住右键拖动 |
| 起身 / 坐到附近空位 | `E` 或「起身 / 坐下」按钮 |
| 离座移动 | `W / A / S / D`，方向随视角变化 |
| 蹲下 | 按住 `C` 或左 `Ctrl` |
| 使用烟雾 | `Q` 或「烟雾」按钮 |
| 暂停 / 重开 / 返回菜单 | `Esc` 或右上暂停按钮，随后选择菜单项 |

起身、换物品和使用烟雾会先收起当前动作。课桌区域与教室边界有碰撞，坐下需要附近有空座。桌面竖书固定在座位前方；抽屉属于场景结构，当前没有手动开合抽屉或举放书本的按键。

切换窗口或隐藏页面会暂停规则。恢复后需要重新按住行动，不会沿用之前的长按或移动输入。移动端没有完整的移动/视角触控方案。

## 老师和同学如何选择行为

老师根据实际朝向、距离和视野观察同学。桌前竖书降低远处正面看到手中道具的程度；侧面和近距离更容易露出。这里使用简化的方向与距离判定，并非完整的三维物体遮挡求解。

看到正在使用的道具才会积累违规证据；声音只会留下调查线索，不直接抓人。老师分别记住见过、听到过的人和位置，再选择板书、扫视、调查或再次检查。藏起动作可以停止新的暴露，但不会清除已经积累的记忆；已经确认身份后，松手不能撤销识破。

四名 AI 同学分别有谨慎、大胆、乐于帮助和容易分心的性格，依据老师朝向、距离和动作风险自行选择物品、收手、观察一会儿再行动，并可使用各自的一枚烟雾。他们必须实际完成动作才能贡献捣乱值，也会被抓。没有固定的队友加分额度，玩家不操作时队友可能获胜，也可能全部被抓后无法继续涨值。

这些是本地可重复的规则与行为规划，不是 LLM，也没有在线 API。普通 NPC 不产生捣乱值，老师选择目标时不读取谁属于捣蛋阵营。

## 烟雾与声音

玩家每局有一枚烟雾，使用后在人物前方形成世界坐标中的遮挡区域。只有穿过烟雾的视线受影响；它不会强制老师转身，也不会取消已开始的粉笔动作。`Q` 当前绑定烟雾，不是固定时长的同学掩护。

音乐、铃声、脚步和动作音效由 Web Audio 合成，没有人声、浏览器语音合成、语音输入或 AI 对话。场内文字用于必要的状态反馈。

## 开发版调校

以下参数仅用于让当前试玩可玩，不声称与原作一致。统一定义位于 `dist/classroom-rules.js`。

| 动作 | 玩家完成一次所需时间 | 捣乱值 | 当前差异 |
| --- | --- | --- | --- |
| 偷吃零食 | 4 秒 | 2 | 包装声较明显 |
| 传纸条 | 5 秒 | 2.5 | 噪声与可见风险较低 |
| 玩手机 | 6.5 秒 | 3.5 | 噪声少，露出时更容易积累证据 |

- 目标捣乱值 100；默认无时限。
- 老师视野角 110°，距离上限 9 个场景单位；证据按实际可见程度和动作风险积累，并缓慢遗忘。
- 识破后的粉笔准备为 0.7 秒；烟雾持续 7 秒、半径 1.9 个场景单位。
- AI 完成动作的速度有个体差异，完成后还会按性格和风险留出观察间歇。

自动验证覆盖确定性、暂停、视野、书本方向遮挡、碰撞、噪声与证据分离、实际队友贡献、烟雾、单人罚站、全队结算，以及不同操作策略的节奏。运行 `npm test`；静态引用检查运行 `npm run check`。
