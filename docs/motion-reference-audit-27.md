## 最关键的差别

1. **运送时与绑桩后不能共用“手藏背后”的姿势。** 运送时学生双臂抬到身旁，肘弯、腕松、指弯，双腿悬空不同步挣动；绑桩后手在背后，肘只向两侧突出。
2. **抓取接触点确实在学生前颈/下颌下方。** 完整预告 25 秒正面近景清楚可见老师黄色手掌包住颈前，学生下巴抬起。只有商店 clip-02 的背面镜头看不出这一点。
3. **先固定接触点，再让肢体动。** 运送时颈部随老师手走，学生躯干、头部、手腿围绕它挣动；不应让学生整个人上下飘出老师手掌。
4. **进食是持物手与食物的整体近景动作。** 空闲手稳定得多，不是两手一起同幅度抖动。原始帧支持小幅上下动，不支持复杂咀嚼、手指持续开合或大幅全身晃动。
5. **写字动作以纸面接触为中心。** 笔、手应一起运动，另一手与坐姿保持支撑；不是用肩部持续大幅甩手来表示写字。

### 动作方向、幅度、时序

- 可信方向：手/笔沿纸面小范围移动，头略低，肩肘维持桌前支撑关系。
- 可信相对幅度：腕/笔尖运动比肩膀小，写字不能变成整条手臂绕肩转圈；桌面是空间约束。
- **无法验证**：笔尖精确轨迹、循环周期、腕关节具体角度。现有镜头持续平移，没有足够长的锁镜头近景，不能写成“原版每 X 秒划 N 次”。

### 握点与运动

- 汉堡主要由左手掌和内弯手指包住侧边，拇指在相对另一侧；物品不能在手掌外悬空，也不能随指尖各自抖动。
- 近景中手与食物作为一组做轻幅上下偏移，2.8→3.2 秒汉堡顶部约上移十几像素（1170×420 裁切视频）。只能作为屏幕幅度参照，不能当固定世界距离。
- 右手不是完全伸直的张掌，也不是紧拳：四指半弯，拇指向侧方离开掌面；手腕可有小幅自然变化，不能抢过持物手的动作。
- **无法验证**：这些短片不是完整连续一局，不能由 2.5→3.8 秒断言原版使用时间为 1.3 秒。用户当前普通物品统一三秒是项目规则，和参考影像计时须分开。
- 用户已指定“进食就是拿着物品上下上下”，此项与可见动作方向一致；无须新增嘴部咀嚼或把道具塞进头部。

## D. 木桩绑定与挣扎

- `motion27-trailer-3000.jpg`、`3200.jpg`、`3500.jpg` 可见讲台两边有已绑学生。绑住状态应绑定木桩坐标，不应跟老师一起转向、位移。

- **无法验证**：绳索具体结法、精确绑定动画时长、手臂何时被绕到背后、自主挣脱是否有固定循环、队友救援的精确手动作。25–26 秒后视频切走，不能把剪辑间隔当绑定时长。需要更长未剪辑实机录像才能称这些细节还原。

## 建议的本轮验收截图

以下为实现建议，不是声称原作数值：

1. 相同机位保存抓住瞬间、运送中间、接近木桩、已绑四张。运送时双臂必须在身体侧前方可见；已绑时才转到背后。
2. 运送侧视检查老师掌面与学生前颈，下巴不穿手、手不离颈；腿悬空且左右不同时迈。
3. 第一人称取汉堡/空手各两张：握指接触食物，空闲手变化小于持物手；手腕不旋成掌面倒置。
4. 写字正侧视：笔尖贴近纸面，髋在椅上，肘腕在桌前；阅读姿势与写字姿势分开。
5. 记录“本轮可见证据已经对齐”与“缺少参考无法验证”两类结果，不笼统写“全部一比一”。

最需要保留的是**肩带摆动、左右肘腕不同相位、前后伸缩、头部侧倾**共同组成的姿势。三个时刻并非双腕在一个窄高度区间的平举。0.5 秒是抽帧间隔，不是已测出的完整挣扎周期。

“手只能朝下”也不能只靠把手掌从固定世界 Y 改为跟前臂解决：25.5 秒右肘与腕形成的弯折、手伸向镜头的深度、手指松弯姿态，与 26 秒右手整组落下是两种不同动作。参考帧没有能精确读出的腕旋前/旋后角度，不能捏造一个角度值称原版。

3. **道具集不全。** 本地抽屉道具池只有零食、纸条、手机、烟雾弹；官方商店/发行商一手资料还确认无人机、麻醉枪、墨水干扰、监控与雷达。不能把这些未做的项写为已完整还原；同样不能凭名称臆造其操作。

### 必须进原版实机逐项测量的六项

1. **版本与房间规则：** 实际可选人数、教师数、胜负条件、时间限制、误抓处罚、房间可调项。公开商店与不同日期预告不是同一版本参数表。
2. **交互与第一人称手感：** FOV、眼高、鼠标灵敏度、坐下/起身/书本/抽屉按键、持物转身限制、移动速度、是否有加速度、选取距离与遮挡。视频无法区分输入速度和相机动画。
3. **完整动作链：** 粉笔命中→眩晕→抓取→行走转弯→绑桩→挣扎→救援/放下的未剪辑多机位录像；测接触点、每段时长、过渡、腕指姿态。现有预告会切走，不覆盖完整链条。
