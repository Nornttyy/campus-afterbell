# 当前课堂试玩

本文说明仓库当前实现。原作的一手证据和未知机制见[原作玩法核验](reference-gameplay.md)；下列数值、机器人策略和按键均属于本地试玩。

## 一局怎么进行

教室有三十个座位：玩家和四名 AI 同学属于捣蛋学生，另外二十五名普通 NPC 只会读书、写字、挠头或翻页。玩家可选择学生或老师；老师局将五名捣蛋 AI 随机分配到三十个座位，其余同学不贡献捣乱值。当前没有真人联机。

坐下打开课桌后会看到三格随机物品，物品池为零食、纸条、手机、烟雾弹，允许抽到同类物品。中心瞄准物品后按 E 拿取，再按住鼠标左键使用。零食、纸条、手机累计使用 3 秒，松开只停止使用，物品仍拿在手里；按 Q 放回。烟雾弹改为点击快速抛出、长按蓄力并松手投掷，约 1.2 秒蓄满，蓄满不会自动投掷。每格分别保存使用进度，完成后消耗该物品，空格经过 3 秒游戏时间补一个随机物品。关掉再打开不会重新抽取，暂停不推进使用或补货。零食、纸条、手机只有坐着使用才增加全队捣乱值；烟雾弹可离座使用，不加分。

进食动作只让握着整件食物的手上下晃动，另一只手放松；不演出捏碎块、送入口中或具体咀嚼。食物保持固定尺寸并贴合手掌。

全队捣乱值达到 100，学生获胜。老师确认违规后投粉笔，命中使学生眩晕。老师靠近抓住后颈、沿过道带到空木桩，再绑住学生。被抓不会立即减少未被绑人数；五名捣蛋学生同时被绑在木桩上，老师才获胜。学生可以救人，AI 同学也会判断时机去解救，获救后能继续游戏。当前没有倒计时或三次全局失败。

## 控制方式

| 功能 | 键鼠与按钮 |
| --- | --- |
| 中心瞄准课桌后打开 / 关闭 | `E`，需坐下 |
| 中心瞄准抽屉中的物品后拿取 | `E`，浅蓝描边标明目标 |
| 中心瞄准书本后放平 / 竖起 | `E`，需坐下，书本状态随座位保存 |
| 使用物品 / 停止使用 | 零食、纸条、手机按住左键，累计 3 秒；烟雾弹点击即抛，长按蓄力、松手投掷 |
| 放回物品 | `Q`，需坐下，保留该格使用进度 |
| 转头和低头 | 开始、恢复游戏时请求锁定鼠标，移动鼠标转向；不支持锁定的浏览器保留右键拖动 |
| 起身 / 坐到附近空位 | `空格` |
| 离座移动 | `W / A / S / D`，方向随视角变化 |
| 蹲下 | 按住 `C` 或左 `Ctrl` |
| 解救被绑队友 | 站立靠近，中心瞄准并按住 `E` 1.6 秒；中断后重计 |
| 老师抓住 / 绑住学生 | 粉笔命中后靠近按 `E` 抓住；带到空木桩前再按 `E` 绑住 |
| 老师放下学生 | `Q` |
| 暂停 / 重开 / 返回菜单 | `Esc` 或右上暂停按钮，随后选择菜单项 |

首次拿取一格物品需要打开课桌；拿出后可以关上课桌继续使用。一次只能拿一件，换物品需要先放回。起身会关上课桌。烟雾弹没有独立技能键，不能凭空释放。课桌区域与教室边界有碰撞，坐下需要附近有空座。书本开合也使用中心瞄准加 E，不增加独立热键；开合过渡暂停时冻结。

切换窗口或隐藏页面会暂停规则。恢复后需要重新按住行动，不会沿用之前的长按或移动输入。移动端没有完整的移动/视角触控方案。

## 老师和同学如何选择行为

老师根据实际朝向、距离和视野观察同学。桌前竖书降低远处正面看到手中道具的程度；放平后不再提供这一遮挡，侧面和近距离更容易露出。这里使用简化的方向与距离判定，并非完整的三维物体遮挡求解。书本的 E 键操作属于本地实现，尚未核实为原作键位。

看到拿在手里的违规道具就会积累证据；声音只会留下调查线索，不直接抓人。老师分别记住见过、听到过的人和位置，再选择板书、扫视、调查或再次检查。放回物品可以停止新的暴露，但不会清除已经积累的记忆；已经确认身份后，松手不能撤销识破。

四名 AI 同学分别有谨慎、大胆、乐于帮助和容易分心的性格，依据老师朝向、距离和动作风险自行选择物品、收手、观察一会儿再行动，遇到危险时也会选择抽屉里实际持有的烟雾弹。他们也各有三格随机物品，用完需要等待补货，不能无限凭空使用。取用时自己的抽屉会打开，中止时放回同一格，保留已经使用的进度。他们必须实际完成动作才能贡献捣乱值，也会被抓。没有固定的队友加分额度，玩家不操作时队友可能获胜，也可能全部被抓后无法继续涨值。此前临时加入的“咳嗽求助”技能已删除。

这些是本地可重复的规则与行为规划，不是 LLM，也没有在线 API。普通 NPC 不产生捣乱值，老师选择目标时不读取谁属于捣蛋阵营。

## 烟雾与声音

烟雾弹从课桌随机出现，E 拿起后点击左键即可快速抛出；长按左键约 1.2 秒蓄满，松手按当前蓄力抛出，越久越远。只在主动松手时消耗该格物品，暂停、失焦、Q 放回会取消蓄力并保留物品。罐体从左手位置出发，按初速度和重力沿抛物线飞行，会与地面、墙壁、天花板和桌面碰撞反弹。落稳停止弹跳后等待 0.5 秒冒烟，碰墙、空中和弹跳阶段不计时，烟团逐渐变大、变浓，持续 7 秒后消散。屏幕中央圆环显示蓄力或其他物品的使用进度。只有穿过烟雾的视线受影响；它不会强制老师转身，也不会取消已开始的粉笔动作。没有每局赠送烟雾、独立库存或烟雾技能键。

音乐、铃声、脚步和动作音效由 Web Audio 合成，没有人声、浏览器语音合成、语音输入或 AI 对话。场内文字用于必要的状态反馈。

## 开发版调校

以下参数仅用于让当前试玩可玩，不声称与原作一致。统一定义位于 `dist/classroom-rules.js`。

| 动作 | 玩家完成一次所需时间 | 捣乱值 | 当前差异 |
| --- | --- | --- | --- |
| 偷吃零食 | 3 秒 | 2 | 包装声较明显 |
| 传纸条 | 3 秒 | 2.5 | 噪声与可见风险较低 |
| 玩手机 | 3 秒 | 3.5 | 噪声少，露出时更容易积累证据 |
| 烟雾弹 | 点击即抛；长按约 1.2 秒蓄满，松手投掷 | 0 | 蓄力增加距离，碰撞后形成遮挡烟雾 |

- 目标捣乱值 100；默认无时限。
- 老师视野角 110°，距离上限 9 个场景单位；证据按实际可见程度和动作风险积累，并缓慢遗忘。
- 识破后的粉笔准备为 0.7 秒；烟雾持续 7 秒、半径 1.9 个场景单位。
- AI 完成动作的速度有个体差异，完成后还会按性格和风险留出观察间歇。

自动验证覆盖确定性、暂停、视野、书本方向遮挡、碰撞、噪声与证据分离、实际队友贡献、烟雾、单人罚站、全队结算，以及不同操作策略的节奏。运行 `npm test`；静态引用检查运行 `npm run check`。

## 已确定但尚未接入的内容

- 核心身份玩法是老师找出混在普通 NPC 中的真人学生；当前已能扮演老师，但对手仍为本地 AI，尚未实现真人联机。
- 白天、晚自习、机房已接入不同光照或交互。三者仍以同一教室建筑为基础，不能记为原作完整地图已复刻。其余校园结构、道具和多人房间待完成。
- 男同学、女同学均已接入用户上色绑定的四指 Tripo 模型，近处和远处使用同一角色资产。眼镜同学使用男生骨架加眼镜，并非已经重做为独立发型皮肤。男女各有十段骨骼动作；走路、持物走路可在动作检视页检查，AI 现在为救援、返回座位和老师押送使用避开课桌的路径，但普通同学仍没有自由巡游。
- 第一人称仍只显示手掌，空手也保留。按用户要求，老师继续使用此前的程序模型，Tripo 老师资产保留但不启用。其余家具、道具的完整模型替换及更多皮肤尚未完成。

## restraint-26：木桩抓捕与救援

2026-11-07 按用户纠正，删除之前的红牌、罚站牌和直接移到讲台旁的抓获方式。学生经历 free → stunned → carried → bound；只有 bound 计入抓获数。粉笔眩晕后无人抓住会恢复；被抓时不能自行移动、使用课桌物品。老师一次只能抓一人，带人时不能再投粉笔，必须走到未占用木桩旁才能绑住，不能在远处执行。Q 可放下，学生返回自由状态。

老师手掌对齐学生真实骨架的后颈。学生被抓时抬手挣扎、交替踢腿；被绑时双手移到身后，躯干与木桩间有绳圈，保留幅度较小的挣扎。骨骼 IK 的结果独立于基础动作，逐帧恢复再求解并平滑过渡，防止累积扭曲；不缩放人物模型。老师视线高度 1.95，与粉笔和选取射线共用同一常量。

解救需要站立靠近、中心瞄准被绑同学，连续按住 E；中央圆环显示进度。松开、走远、暂停会中断。获救后清除绑定和旧识破标记、恢复行动能力，木桩重新空闲。AI 同学会在老师离开附近后择机沿过道靠近并解救，随后返回座位。AI 老师也必须真实走到眩晕同学旁抓住，再沿过道押送到空木桩。

眩晕 5 秒、抓取范围 1.55、解救 1.6 秒、带人移动速度和动画幅度均为当前本地调校，并非已经测得的原作参数。粉笔的初速 16、重力 1.6、间隔 0.72 秒保留。误抓普通 NPC 不增加抓获数；真人联机和其余道具尚未实现。

晚自习保留随老师视角移动的手电，AI 夜间观察锥角约 49°、范围 12。机房保留中心瞄准屏幕 E 开启游戏、按住左键累计 3 秒增加 2.5 捣乱值、Q 切回课件；眩晕、被抓或被绑时停止电脑游戏和手持物品使用。三种场景仍共用基础教室结构。
