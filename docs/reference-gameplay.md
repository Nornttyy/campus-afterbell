# 《我带过的最差一届》玩法核验

核验日期：2026-11-05。本文仅记录取得的一手文字和实际查看的官方视频预览图，不代表已玩过原版，也不把本地原型规则当作原作规则。

## 证据来源与版本

- **S1：官方 Steam 商店**：[中文页面](https://store.steampowered.com/app/5175310/Worst_Class_Ever/?l=schinese)。页面仍写最多六人，一名教师玩家、五名学生玩家；真人学生混在数十名 NPC 同学中。这里的教师是玩家角色，不能把本地机器人策略说成原作机制。
- **S2：开发者官方公告**：[Steam 社区中心内的官方公告](https://steamcommunity.com/app/5175310)。2026-10-23 公告说明学生可以拿着物品离开座位；2026-10-26/27 正式版预告说明人数上限将增至八人，并加入可调整人数、教师数量、道具出现率等房间选项。2026-11-02 公告表示 Demo 将于 11 月 3 日下架。六人 Demo 的行为证据与八人正式版公告分开使用。
- **S3：2P Games 发行商新闻稿**：[2026-10-27 英文原稿](https://www.gamespress.com/en-GB/Worst-Class-Ever-Ranks-No-1-in-Player-Count-During-Steam-Next-Fest)。这是发行商发布的材料，不是玩家评测。
- **S4：开发者视频**：[《全班几十个学生里，只有5个是真人！》](https://www.bilibili.com/video/BV1XQaU6CEmd/)，作者“夜之黄泉丨顽核社”，2026-10-02。Steam 商店列出的官方账号与公开视频作者元数据一致。这段材料早于 Demo，不能据此保证正式版键位或平衡数值未变。

## 已证实的核心行为

| 内容 | 取得的证据 | 支持范围 |
| --- | --- | --- |
| 学生伪装、教师辨认 | S1 描述学生躲在 NPC 中偷吃、传纸条、玩手机；教师要找出全部捣蛋者。 | 非对称辨认与伪装是玩法核心。未提供精确结算算法。 |
| 学生累积捣乱值 | S3 明确描述通过课堂恶作剧累积 `mischief score`。 | 有分值或进度这一目标；未给分值、阈值或任务配额。 |
| 桌面书本和桌下道具 | S4 可见第一人称双手、面前竖起的大书、朝桌下看的视角以及桌沿下方持用的手机和物品。 | 可确认空间交互表现；不能仅凭预览图确定书本控制键或完整遮挡算法。 |
| 抽屉与藏动作 | S3 提到低头到桌内、装作记笔记等可被教师观察到的动作；S4 可见桌前抽屉面板和把手。 | 桌子、抽屉、身体姿态参与可见行为；开关抽屉的具体操作尚未确认。 |
| 离座移动 | S2 的 10 月 23 日公告明确说明可拿着物品离开座位。 | 能离座；不能据此补写蹲伏键、换座条件或行动速度。 |
| 教师板书与观察 | S3 描述教师写板书同时观察和听动静，回头检查学生。 | 板书是教师实际行为。没有取得“板书恢复体力”的一手明确说明。 |
| 粉笔、红牌和罚站 | S3 描述教师用粉笔点名违规者、出红牌，并将学生留在讲台旁。 | 抓获后有讲台旁罚站表现；不支持“玩家被看见一次就结束全队对局”或“三次全局怀疑即失败”。 |
| 道具对抗 | S1、S3 确认烟雾弹、麻醉枪、无人机，以及墨水干扰、摄像头和雷达；S3 描述烟雾可帮助同伴脱身。S4 可见大范围烟雾和侦察装置。 | 道具改变观察、隐蔽和协作条件；每件道具归属、冷却及救援流程仍需逐项核实。 |

## 仍未证实，不能冒充原版参数

- 教师体力总量；抓人、抱人或其他行动是否消耗体力；写板书是否恢复体力及恢复速率。
- 学生捣乱值的胜利阈值、是否全队共享、各种动作奖励、计时上限以及超时结算。
- 具体蹲伏、移动、离座、换座、举书、收书、抽屉和使用物品的键位，以及按住或切换方式。
- 粉笔命中、红牌和抓起学生之间的必需操作顺序；误抓 NPC 的惩罚。
- 罚站学生能否自主操作、救援所需的距离/时间/键位，以及被救后的状态。
- NPC 的完整行为逻辑、教师和学生可视范围、遮挡判定、道具持续时间、出现率与冷却。

“九项任务、个人必须完成三种、180 秒、被认出一次立刻结束”不是上述一手证据确认的原版规则；此前“160 分、三次怀疑失败”也不是。需要可玩的本地版本时，未核实的数值应集中说明为开发版调校，并保留调整入口。

## 与本地试玩的边界

这些证据支持研究第一人称桌后观察、桌下行动、姿态与移动、教师辨认及罚站和道具协作。不能据此宣称已复现原作的完整交互和结算规则。

本地当前功能、按键和调校单独记录在[当前课堂试玩](gameplay.md)。其中 100 捣乱值、无倒计时、动作时间/奖励、烟雾持续时间、视野与证据参数均是开发选择，不是从上述来源核实的原版数值。本地教师和同学由规则程序控制，不接入 LLM；目前也没有一手证据证明原作使用 LLM 或任何特定 AI 架构。

## 2026-11-07 增量核验

再次读取 S1 和 S3。官方列出日间课堂、晚自习、电脑教室；发行商说明晚自习由老师用手电巡查，机房学生可偷偷玩电脑游戏。6 人 Demo 说明与正式版 8 人公告继续区分。当前本地实现只采用已确认的身份、粉笔/红牌、夜间手电和机房行为，不把新代码的教室布局、键位、冷却或命中窗口写为官方数据。

本轮没有得到可直接游玩的原版正式版，未声称亲自试玩原作。无人机、麻醉枪、墨水、监控和雷达虽有一手文字支持，但交互细节尚未核实，因此没有补写成任意技能。
