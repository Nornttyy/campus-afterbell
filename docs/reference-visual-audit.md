## 教室、镜头与尺寸关系

- **书本分布**：03、04、05、12 中大多数桌面平摊练习本，少数学生举书；01、02、06 的玩家座位有竖书。全班统一竖书会遮掉人物躯干和手势。主场景正在修复此项，需用新截图验收。
- **镜头**：官方 05 从讲台附近朝后看，视线接近学生头部；09、11、12 提供人物近景与侧面。旧菜单的俯拍角度更高，桌面占比大、腿和肩身缩短。应保留一个接近坐姿眼高的审查镜头，才能判断人物体积，而不是仅以俯拍菜单评价。
- **桌椅与身体**：12 显示桌沿约在坐姿胸下方，双前臂可自然平伸；膝盖在桌斗下，脚落到椅腿范围。椅背在肩下并露出左右边，不应把人物躯干完全吞进椅背或桌板。
- **抽屉**：01、02、12 的抽屉是可伸出桌沿的容器，有侧壁、前挡板和黑把手。它不是桌板下的一片灰色空隙。当前场景已开始修复，仍需确认人物膝腿和抽屉不穿插。
- **桌面**：01、09 的暖黄木纹沿桌面有连续方向，边缘圆润并带厚度。旧截图的木纹较均匀、缺少边缘高光。当前材质修改应避免再用粗黑随机噪点替代木纹。
- **地面**：官方近景是浅灰水磨石，大颗粒与细颗粒混合，接缝细、格子大。旧基线黑白碎点密且均匀、地面抢眼。此项正在修复，人物对比不应再受高频地面干扰。
- **光照**：03、05、09、12 的窗侧有清楚的斜向日光区域和接触阴影，人物正面仍能读出脸和衣服；皮肤偏暖桃色。旧菜单主体较灰、皮肤偏奶白。先核对灯光与颜色管理，再判断是否需要改肤色材质。

下一次验收应保留相同取景，至少包含：完整菜单、单个学生正面近景、侧面坐姿、后脑肩背、正常桌前双手、抽屉取物双手。比较时不把正在修改的代码状态当作已经看到的结果。

## 新截图补充：model-first-08

已实际查看 `qa/screenshots/model-first-08.png`，并与官方 `steam-11.jpg` 再次对照。以下替代前文中相应的旧基线判断。

1. 白色胸肩片出现大量碎三角、锯齿和蓝色破口，多个远近角色都有。这是当前最显眼的问题。官方白色拼片是连续表面，有清楚的领口和中线，不能用叠在身体上的零碎白片近似。
2. 前景紫发女生仍有平顶、过直的冠部与连续横刘海；侧分男生刘海仍像直帽檐。官方 09、11、12 的冠部圆弧、前伸刘海与侧鬓必须分别形成轮廓。
3. 眼白在脸上的占比偏小，下巴仍接近平底。建议先小幅扩大眼白并收圆两颊再拍同角度，不以整体缩小脸部代替修正。这里不宣称一个未经正交测量的百分比是原作参数。
4. 肩头尺度已有改善：前景女生肩部外宽与头发外宽接近，不需要盲目整体扩肩。更明显的差异是直背、上臂下垂、手悬在书边；参考 11、12 应让肩、肘、腕共同前移，掌指与书面或桌面接触。
5. 平摊和竖书的混合已让人物躯干更容易看到；新地面也比旧图安静。这两项不再按旧状态评价。
6. 新图整体仍比官方 05、09、11 灰，前景皮肤偏灰米色、校服蓝色较弱。应先对照曝光、色调映射和窗侧亮暗关系，再单独改肤色。继续增加地面噪声不能解决这个差异。
