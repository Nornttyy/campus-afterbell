### 实际验到了什么

- 主代理已通过 **CUA 操作使用生产渲染与规则的 QA 页面**，查看老师抓颈和学生绑柱；抓颈记录见 `qa/screenshots/teacher-grip-29.jpg`。截图底部的定位按钮及测试目标数属于 QA 工具，不是声称原版存在的游戏内容。
- 主代理实际按住 **E 3400 毫秒**完成救援：绑定计数 `caught` 从 **1 变 0**，可行动队友数从 **4 变 5**。这是本实现的交互结果，**不代表原版救援时长测得为 3.4 秒**。
- 动作检查使用真实导入网格而非骨骼代理点。测试发现手腕位置正确时，末节手指仍可能埋入木柱，已调整握点与松指方向；男、女、眼镜学生均测试真实指尖蒙皮在柱外、捕获切换连续、骨长不变、救下后复原。手部、导入模型及第一人称动作相关 **23 项回归通过**。
- 最后正式老师开局发现旧朝向正对近墙，改到办公室净空区并朝向开门。CUA 实际从 `(6.70, 9.60)` 按 W 走到 `(7.41, 5.67)`，穿过出口进入走廊，未被家具或门挡住；见 `qa/screenshots/teacher-spawn-29c.jpg`。新增出生点净空/正向通路检查，相关地图和教师规则 21 项通过。
- 正式菜单已选择学生/阶梯教室并进入、起身移动和返回菜单；开发控制台未出现错误或警告。校园 QA 的完整办公室→前门→台阶→后门→电梯路线实际走通，并按 E 成功切换机房。跨台阶携带学生镜头与身体高度错层已修复。全套 **100 项回归通过**；最终头部再导出后 23 项角色专项通过。
- 可点击的阶段检查入口为 `qa/capture-review.html`；完整流程检查仍要与实际游戏结合。测试通过证明覆盖到的功能与形变约束，不证明玩法、外观或手感已全面一比一。

### 本轮仍未复刻或未核实

1. **真人联机与识别真人的完整结构尚未完成。** 当前浏览器原型仍以本地玩家和 AI 推进，不把 AI 学生当作网络真人房间、同步和断线重连已经完成。
2. **面部表情和所有皮肤尚未补齐。** 学生固定表情与原视频命中、挣扎的表情差别仍在；老师和眼镜学生的模型改进不能替代全角色正侧背验收。
3. **校园没有原版精确测绘。** 已有连续活动区域和真实阶梯，但不能确认原版所有房间、楼层、门位、距离和道具点均已对应；当前装饰、纹理与光照也仍为重建。
4. **动作细时序和规则数值仍有未知。** 视频可读“抓错了！体力 -40”和“恢复20体力”，但全部触发时点、体力速率、眩晕/救援时长、投掷参数与 0 体力限制并未实机量测。误抓可绑、绑柱吹泡泡等已记录的行为，不因本轮动作修复就自动算作完整实现。
5. **全部道具、音效/语音和 UI 尚非原版完整内容。** 已看材料不足以证明所有掉落池、道具用途、胜负优先级、声音和字体一致；本轮未核验音轨，不能称已还原自然语音或全部音效。

### 本轮已落实且实际查看的局部修复

- 抓取动作根据官方预告 25 / 25.5 / 26 秒的可见关系重建：肩线从一边高到另一边高，两侧肘腕轮流升降，前臂会向前伸，头保持后仰。手掌方向与同一段动作关联，不再按独立正弦与手臂错拍。

- **书本分布**：03、04、05、12 中大多数桌面平摊练习本，少数学生举书；01、02、06 的玩家座位有竖书。全班统一竖书会遮掉人物躯干和手势。主场景正在修复此项，需用新截图验收。
- **镜头**：官方 05 从讲台附近朝后看，视线接近学生头部；09、11、12 提供人物近景与侧面。旧菜单的俯拍角度更高，桌面占比大、腿和肩身缩短。应保留一个接近坐姿眼高的审查镜头，才能判断人物体积，而不是仅以俯拍菜单评价。
- **桌椅与身体**：12 显示桌沿约在坐姿胸下方，双前臂可自然平伸；膝盖在桌斗下，脚落到椅腿范围。椅背在肩下并露出左右边，不应把人物躯干完全吞进椅背或桌板。

- **桌面**：01、09 的暖黄木纹沿桌面有连续方向，边缘圆润并带厚度。旧截图的木纹较均匀、缺少边缘高光。当前材质修改应避免再用粗黑随机噪点替代木纹。
