# campus-82 · 阅读动作衔接

用户本轮优先级：接受轻微穿模，优先对照原作姿势、幅度和节奏；不以避让桌子为理由缩小动作或抬高手。用户制作的第一人称待机、移动、爬行六组动画保持原样。

## 实现

- 看书分为接触、抬书、放回、松手。双手读取同一个书本变换，避免各自平滑造成握点分离。
- 返回时保留阅读手势，直到书放稳并松手才显示笔、开始写字。离座或更换书本来源时清理旧副本。
- 阅读书本位置降低，四种学生眼睛能露出；书本大小未改。阅读期间跳过桌面避让，允许轻微重叠。
- 动画检查页增加“看书→写字→听课”循环。

## 证据与验证

- 参考：用户提供的普通教室截图，以及本机保存的原版 `06-student-look-sit-00m48s.mp4` 片段。仅作为可见姿态参照，未从原版测量本轮抬书/放书精确时间；没有声称观看全部视频或完成全部动作还原。
- 对四个实际 GLB 检查手部蒙皮与运动书本接触、单帧位移、放书后才显示笔，以及书本来源清理。阅读的桌面轻微重叠改为记录，不再作为姿势必须抬高的依据；其他物品、写字等检查保留。
- 完整 `npm test`：1090 通过，0 失败、0 跳过。本轮也修正了前版交互改为 2 秒后仍按 3 秒计算的旧测试采样时刻；运行时交互时长未再修改。
- `npm run check`：通过（127 个脚本、322 个本地引用）。
- 浏览器查看单人正式入口及完整普通教室渲染；本轮控制台无错误。截图留在本机 `art-source/release82/classroom-82.jpg`，参考视频不发布。
